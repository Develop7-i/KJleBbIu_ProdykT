Это ошибка 403 Forbidden от серверов OpenStreetMap: они блокируют загрузку тайлов (фрагментов карты) для вашего проекта. 

На скриншоте чётко видно сообщение: «App is not following the tile usage policy of OpenStreetMap’s volunteer-run servers» — то есть ваше приложение нарушает правила использования тайлов OSM.

Почему это происходит (и почему раньше могло работать)
Серверы OpenStreetMap — это инфраструктура на волонтёрских мощностях, и у них жёсткие лимиты:

Для локальных файлов. Если вы просто открываете index.html двойным кликом (протокол file://), браузер не отправляет заголовок Referer. А OSM требует этот заголовок, чтобы понимать, с какого сайта идёт запрос. Без него — автоматический бан. 
Для сайтов без домена. Если проект лежит на временном адресе вроде 127.0.0.1, localhost или короткой ссылке для предпросмотра — OSM тоже блокирует такие запросы, считая их «неидентифицируемыми».
Превышение лимита запросов. Даже на реальном сайте можно получить бан, если карта часто перерисовывается (зум, панорамирование) и отправляется слишком много запросов подряд.
Отсутствие атрибуции. В коде Leaflet должна быть строка с атрибуцией (в вашем коде она есть, но при блокировке это уже не спасает).
Как быстро исправить для команды (3 рабочих варианта)
Учитывая, что у вас студенческий/прототипный проект и в команде 3 человека, выбирайте по ситуации:

Вариант 1. Самый простой (для локальной разработки)
Если вы просто тестируете код на компьютере, запустите локальный сервер, а не открывайте файл. Это сразу решит проблему с Referer. 

VS Code: установите расширение Live Server, нажмите «Go Live» — карта заработает.
Python: в папке с файлом выполните python -m http.server и откройте localhost:8000.
Node.js: используйте http-server.
Это позволит вам спокойно доделывать 3D-модели и логику прогноза, не меняя код карты.

Вариант 2. Для публикации и показа (бесплатный и стабильный)
Замените слой тайлов OpenStreetMap на Thunderforest / OpenMapTiles — у них есть бесплатный тариф для небольших проектов, и они не блокируют так агрессивно.

Нужно поменять всего одну строчку в вашем JS (в функции initMap):

javascript
// БЫЛО (заблокировано):
L.tileLayer("https://tile.openstreetmap.org/{z}/{x}/{y}.png", {
  attribution: "© OpenStreetMap"
}).addTo(map);

// СТАЛО (работает стабильно):
L.tileLayer('https://a.tile.opentopomap.org/{z}/{x}/{y}.png', {
  attribution: '© OpenStreetMap, © OpenTopoMap'
}).addTo(map);
OpenTopoMap — это отличный вариант для рыболовного приложения: там сразу видны рельеф, высоты и русла рек, что даже атмосфернее для вашей темы.

Вариант 3. Если нужен именно стиль OSM
Используйте MapTiler — у них есть бесплатный ключ API для студентов и небольших проектов.

Регистрируетесь на maptiler.com, получаете ключ.
Меняете слой в Leaflet:
javascript
L.tileLayer('https://api.maptiler.com/maps/streets/{z}/{x}/{y}.png?key=ВАШ_КЛЮЧ', {
  attribution: '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> <a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>'
}).addTo(map);
Что делать прямо сейчас
Учитывая вашу задачу (показать 3D-рыб и прогноз), я рекомендую Вариант 2 (OpenTopoMap). Это не требует регистрации, не требует ключей, и выглядит даже тематичнее для рыбалки.

Вот исправленный фрагмент кода для вашей функции initMap (замените им текущий вызов L.tileLayer):

javascript
function initMap() {
  if (map) return;

  map = L.map("map").setView([54.75, 87.2], 7);

  // ИСПРАВЛЕННЫЙ СЛОЙ: OpenTopoMap (не блокируется, есть рельеф)
  L.tileLayer('https://a.tile.opentopomap.org/{z}/{x}/{y}.png', {
    attribution: '© OpenStreetMap, © OpenTopoMap',
    maxZoom: 17
  }).addTo(map);

  PONDS.forEach(function (pond) {
    L.marker(pond.coords, { title: pond.name })
      .addTo(map)
      .bindPopup(pond.name)
      .on("click", function () { showPond(pond); });
  });

  setTimeout(function () { map.invalidateSize(); }, 100);
}

Написал инит мап, где ошибка?

В этом фрагменте закралась ошибка — после строки attribution пропущена запятая:

javascript
L.tileLayer("https://tile.openstreetmap.org/{z}/{x}/{y}.png", {
  attribution: "© OpenStreetMap, © OpenTopoMap"   // ← нет запятой!
  maxZoom: 18
}).addTo(map);
Из-за этого скрипт вообще не запустится: браузер упадёт с ошибкой Unexpected identifier и карта не появится. Свойства объекта внутри { } разделяются запятыми, так же как элементы списка. Правильно так:

javascript
L.tileLayer("https://tile.openstreetmap.org/{z}/{x}/{y}.png", {
  attribution: "© OpenStreetMap, © OpenTopoMap",  // запятая на месте
  maxZoom: 18
}).addTo(map);
