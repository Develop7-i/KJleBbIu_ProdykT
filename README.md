Разработать веб-приложение, которое анализирует различные данные (погода, фазы луны, время года, исторические данные о клеве) для предсказания вероятности удачного клева в выбранном пользователем регионе и водоеме.

Frontend-разработчик: Ответственен за пользовательский интерфейс, дизайн, интерактивность и взаимодействие с пользователем.

Backend-разработчик: Ответственен за логику приложения, сбор и обработку данных, алгоритм прогнозирования и API.

Team Lead: Ответственен за общее руководство проектом, координацию команды, архитектуру, а также за реализацию 3D-моделей рыбок.

стек: HTML, CSS, JS. Данные хранятся в Json или JS модулях.
